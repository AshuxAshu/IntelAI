# Assets License Manifest

All textures and decor meshes are locally generated procedural stand-ins
dedicated to the public domain under CC0-1.0. The SO-101 robot meshes are the
official TheRobotStudio/SO-ARM100 simulation assets (obtained via the pick-101
repository mirror); upstream licenses them CC-BY-NC-4.0, which is outside this
team's internal allowlist. The mentor guidance explicitly permits publicly
available SO-101 models, so the swap was made and the actual upstream terms are
recorded here verbatim rather than assumed. Team decision on NC usage in the
competition context is pending; if disallowed, revert to the CC0 procedural
stand-ins from the prior revision.
